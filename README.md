# Pathfinder CLI

CLI tool for finding a path for running.

## Installation

```bash
git clone https://github.com/subaru3577/17_pathfinder.git
cd 17_pathfinder
uv pip install -e .
```

## Script for CLI

1. To find a path for running
```bash
uv run pathfinder "Leeds, United Kingdom" --start "Leeds Station"
```
